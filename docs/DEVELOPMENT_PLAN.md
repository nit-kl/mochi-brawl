# DEVELOPMENT_PLAN

## スマホ操作パネルの視界改善（完了）

- スマホ横画面の対戦中だけゲーム画面を中央に収め、ページ左右に操作専用エリアを確保する
- 左側は仮想スティック、右側はジャンプ・攻撃・必殺・防御の縦4ボタン。キャンバスを覆わない
- DOM の Pointer Events でマルチタッチ入力を受け、Safe Area と画面回転に追従する

## 方向別必殺と共通防御（完了）

- 4キャラそれぞれにダメージ判定付きの下必殺を追加。上必殺にも既存のダメージ判定がある
- 下入力 + 必殺で下必殺、上入力 + 必殺で上必殺、方向なしで横必殺
- 全員共通の地上防御。押している間は移動と技を止め、被弾を防ぐ。維持・被弾で耐久値が減り、使い切ると一時的に使えない
- PC は 1P `L` / 2P `/`、スマホ横画面は防御ボタン。CPU も近距離で相手の攻撃を見て防御を選ぶ
- 下必殺の専用画像が無ければ通常攻撃画像を使う

## 4キャラロスター（完了）

- けろたん、ぼてろを追加。性能と技は `CharacterDefinition` に置く
- キャラ選択は2列×2行。1P、2P（CPU またはローカル）を順に選び、同キャラ対戦も可能
- 各キャラの `concept/`、`portraits/`、`sprites/` を整備。`select.png` と `hud.png` は配置時だけ表示
- 提供画像を参照して、けろたん・ぼてろの透過スプライト8種類と選択・HUD画像を配置。画像が欠けた場合は Placeholder または待機画像へ戻る
- 透過8ポーズ原画からの書き出しスクリプトを用意。必要に応じて各動作のコマと表示倍率・足元を調整できる

Milestone 01 から 08、09-A、09-A2、09-B、09-C、09-D、10、11 は実装済み。番号はこれまでの実績に合わせてある。その後、下方向 KO をやめて常設床のアリーナにした。

## Milestone 01: 移動・ジャンプ・PC/スマホ入力（完了）

- スマホ横画面: 左下の仮想スティック、右下のジャンプ
- PC ではタッチ UI を非表示
- 2 段ジャンプは入れていない

## Milestone 02: 2キャラクター・落下・復活・3ストック・勝敗（完了）

- 1P（青）と 2P（橙）を左右に配置
- 1P はキーボードとタッチ、2P は矢印キー
- 画面下への落下でストックが 1 つ減る（四方向の KO 境界は Milestone 04）
- 3 ストック
- 足場上へ復活。直後は落下で連続してストックが減らない
- ストック 0 で勝敗。R キーまたはタップで再戦

## Milestone 03: 通常攻撃・ヒット判定（完了）

- 1P は J、2P は Enter、スマホは攻撃ボタン
- 通常攻撃は 1 種類。startup / active / recovery
- Hitbox は攻撃中だけ有効。Hurtbox は被弾用。物理コライダーとは分ける
- 向いている方向へ Hitbox を出す
- 1 回の攻撃は同じ相手に 1 ヒット
- 攻撃中も移動できる（`canMoveDuringAttack`）
- ダメージ% と吹き飛ばしは Milestone 04

## Milestone 04: ダメージ%・吹き飛ばし・KO境界（完了）

- 各 Fighter が `damagePercent` を持つ。ヒットで増え、KO 後の復活で 0% に戻る
- 通常攻撃のダメージは 8%。`AttackDefinition` に置く
- 吹き飛ばしは `baseKnockback + ヒット後のダメージ% × knockbackScaling`
- 方向は前方やや上。角度は `knockbackAngleDegrees`
- `knockbackLockMs` のあいだは移動入力で速度を上書きしない。終了後も横速度は残り、空中で減衰する。着地すると通常移動に戻る
- KO 境界は左・右・上・下。`PlaceholderStage` の設定
- HUD にストックとダメージ%を出す
- F3 で Hurtbox と KO 境界を表示する。普段はオフ
- 本格的なヒットストップと被弾硬直はまだ入れない

## Milestone 05: もちまるの性能と固有アクション（完了）

- `CharacterDefinition` に移動、ジャンプ回数、重力、重量、通常攻撃、必殺、上必殺を置く
- 1P はもちまる。HUD の名前は「もちまる」
- 2 段ジャンプ。着地と KO 復活で回数を戻す
- 通常攻撃「ぺち」。3 段コンボにはしていない
- 必殺「ぐるぐる突進」。上入力が強いときは「ふうせんジャンプ」
- ふうせんジャンプは空中で着地まで 1 回。上昇中に弱い Hitbox
- weight で吹き飛ばしを割る。もちまるは 1.0
- 2P は仮キャラのまま。通常攻撃と 1 段ジャンプ
- 必殺が成立したフレームでは、同じフレームのジャンプを発動せず、ジャンプ回数も減らさない
- 3 段コンボ、方向通常攻撃、ぽてち固有性能はまだ入れない

## Milestone 06: ぽてちの性能と固有アクション（完了）

- 2P をぽてちに置き換え。HUD の名前は「ぽてち」
- 移動は遅め、ジャンプは低め、weight は 1.4、重力は 1.1
- 通常攻撃「どすっ」。発生は遅め、威力と吹き飛ばしは強め
- 必殺「どっすーん！」。`slam` で前方へ跳んでから着地時に 1 回だけ当たる。着地しない場合は最大時間で解除する
- 上必殺「ばねジャンプ」。ふうせんジャンプより低く、横移動も小さい
- 空中の上必殺は着地まで 1 回。上必殺が成立したフレームはジャンプを消費しない
- 仮表示は物理ボディより大きい。Hurtbox と足場判定のサイズは変えない
- 方向通常攻撃、3 段コンボ、本番画像はまだ入れない

## Milestone 07: スマホUI/UX仕上げ（完了）

- 横持ち前提。左手は仮想スティック、右手はジャンプ・攻撃・必殺だけ
- 右手は必殺を上、ジャンプを左下、攻撃を右下に置く。タッチ領域は 64 CSS px
- 攻撃は赤、必殺は紫、ジャンプは青。押しているあいだは縮んで明るくなり、枠が白くなる
- スティックは左下。入力中はノブが指の方向へ動き、離すと中央へ戻る
- スティックと各ボタンは pointerId ごとに持つ。右手を離しても左の移動は残る
- タッチ端末の縦向きでは「端末を横向きにしてください」を出し、操作 UI は出さない
- HUD はスマホでは左上にもちまる、右上にぽてち。Safe Area の内側に置く
- PC ではスティック、タッチボタン、縦向き案内を出さない
- 判定は画面幅ではなく、粗いポインタかつホバー不可またはタッチ可能
- 方向つき通常攻撃とゲームパッドはまだ入れない

## Milestone 08: おひるね草原・ステージ縮小（完了）

- ステージ定義 `ohirune_meadow`。出現、復活、KO 境界、足場、縮小フェーズを持つ

- 180 秒で浮遊足場を予告のあと消す。300 秒でメイン足場を幅 520 まで左右均等に縮める
- 当たり判定は表示と同じフレームで更新する。消えた場所にいたキャラクターは落ちる
- 当時は KO 境界を縮めなかった。再戦でシーンを初期状態に戻す。床を縮める方式は、その後の仕様変更で左右 KO を寄せる方式に替えた
- 当時は `?shrink=fast` で 10 秒と 20 秒に短縮できた。この時間縮小と台座の帯は、その後の仕様変更で外した
- 7 分以降の吹き飛ばし補正は入れていない

## Milestone 10: タイトルから対戦までの流れ（完了）

- `TitleScene` → `CharacterSelectScene` → `StageSelectScene` → `BattleScene`
- 1P がキャラクターを選ぶ。2P は選ばれなかった側
- ステージは `STAGE_LISTINGS`。今はおひるね草原だけ
- 選択結果は `MatchSetup` として Phaser の registry に置く
- HUD の名前とスプライトは、選んだ `CharacterDefinition` から出す
- 勝敗後は R または「再戦」、Esc または「キャラ選択へ」。画面のどこかをタップしての再戦はしない
- キャラクター性能、ダメージ、吹き飛ばし、ストック、ステージ縮小は変えていない

## Milestone 11: CPU対戦（完了）

- `MatchSetup.mode` は `cpu` または `local_vs`
- スマホは 1P が操作し、2P は CPU。PC のタイトルで「ひとりで」「ふたりで」を選ぶ
- `CpuInput` が `PlayerInput` を作る。Fighter は相手が CPU かを見ない
- 判断は 100〜250ms ごと。接近、通常攻撃、たまに必殺、高い足場へのジャンプ。この時点では床の外からの復帰も入っていた。復帰は Milestone 12 で外した
- 技の違いは `CharacterDefinition` の motion から見る。難易度の数値は `normal` だけ
- 足場は `StageRuntime.livePlatforms()` の今の幅を使う
- `local_vs` の 2P は矢印キーのまま。CPU は動かない
- 性能、ダメージ、吹き飛ばし、ストック数は変えていない

## 仕様変更: 下KO廃止・常設床（完了）

- KO は左・右・上。`bottomKoEnabled: false` のステージは下ではストックが減らない
- おひるね草原のメイン足場は幅 8000 の常設床。草の絵は幅 820 のまま
- Phase 1 は浮遊足場が消える。落ちたあとは下の床に着く
- その後、台座の帯と、時間で足場や KO 範囲を狭くする処理はやめた
- 上は -300 のまま。ふうせんジャンプとばねジャンプ、2 段ジャンプは空中戦の移動として残す
- キャラクター性能、攻撃力、knockback、weight、ストック数、スプライト、HUD は変えていない

## Milestone 12: 1P vs CPU の正式化（完了）

- 対戦モードは `cpu` と `local_vs` のまま。スマホは CPU、PC は「ひとりで」「ふたりで」
- `CpuInput` が `PlayerInput` を作る。Fighter に CPU 用の分岐は無い
- Normal の判断は 150〜250ms。攻撃後に待ち、一定確率で判断を飛ばす
- 接近、近距離の通常攻撃、中距離の横必殺、相手が上のときのジャンプと上必殺。空中でも相手方向へ歩く
- 上必殺は空中の位置取りに使う。ジャンプから 2 段ジャンプ、上必殺で下から戻る処理は無い
- 左右の回避は `currentKoBounds()` と `edgeSafetyDistance`。KO 線から約 130px 以内は中央へ戻る
- 技の違いは `moveSpeed` と `AttackDefinition.motion`。キャラクター名では分岐しない
- 相手キャラクターは `opponentProfile`。F3 のときだけ CPU の状態、距離、判断待ち、端の危険を出す
- キャラクター性能、攻撃性能、ストック、KO 線、Phase、スプライト、ステージ、HUD、ヒット演出は変えていない
