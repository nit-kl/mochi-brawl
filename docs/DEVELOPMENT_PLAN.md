# DEVELOPMENT_PLAN

Milestone 01 と 02 は実装済み。番号はこれまでの実績に合わせてある。

## Milestone 00: 開発基盤

- Vite + TypeScript + Phaser 4 セットアップ
- GitHub リポジトリ
- `main` ブランチを安定版として運用

## Milestone 01: 移動・ジャンプ・PC/スマホ入力（完了）

- 仮の矩形キャラクター
- 足場 1 つ、重力、1 段ジャンプ
- カメラ固定
- `KeyboardInput` / `TouchInput` を `PlayerInput` にまとめる
- PC: A/D で移動、Space または W でジャンプ
- スマホ横画面: 左下の仮想スティック、右下のジャンプ
- PC ではタッチ UI を非表示
- 2 段ジャンプは入れていない

## Milestone 02: 2キャラクター・落下・復活・3ストック・勝敗（完了）

- 1P（青）と 2P（橙）を左右に配置
- 1P はキーボードとタッチ、2P は矢印キー
- 画面下への落下でストックが 1 つ減る
- 3 ストック
- 足場上へ復活。直後は落下で連続してストックが減らない
- ストック 0 で勝敗。R キーまたはタップで再戦

## Milestone 03: 通常攻撃・ヒット判定（完了）

- 1P は J、2P は Enter、スマホは攻撃ボタン
- 通常攻撃は 1 種類。startup / active / recovery
- Hitbox は攻撃中だけ有効。Hurtbox は被弾用。物理コライダーとは分ける
- 向いている方向へ Hitbox を出す
- 1 回の攻撃は同じ相手に 1 ヒット
- 攻撃中も移動できる（`canMoveDuringAttack`）
- ダメージ% と吹き飛ばしはまだ入れない

## Milestone 04: ダメージ%・吹き飛ばし

- ヒット時にダメージ%を加算する
- ダメージが高いほど吹き飛びを強くする
- 被弾硬直
- ヒットストップはまだ入れない

## Milestone 05: もちまる固有アクション

- 方向攻撃
- ぐるぐる突進
- ふうせんジャンプ

## Milestone 06: ぽてち固有アクション
