# DEVELOPMENT_PLAN

Milestone 01 から 08、09-A、09-A2、09-B、09-C、09-D は実装済み。番号はこれまでの実績に合わせてある。

## Milestone 00: 開発基盤

- Vite + TypeScript + Phaser 4 セットアップ
- GitHub リポジトリ
- `main` ブランチを安定版として運用

## Milestone 01: 移動・ジャンプ・PC/スマホ入力（完了）

- 仮の矩形キャラクター
- 足場 1 つ、重力、1 段ジャンプ
- カメラ固定
- `KeyboardInput` / `TouchInput` を `PlayerInput` にまとめる
- PC: A/D で移動、Space または W でジャンプ
- スマホ横画面: 左下の仮想スティック、右下のジャンプ
- PC ではタッチ UI を非表示
- 2 段ジャンプは入れていない

## Milestone 02: 2キャラクター・落下・復活・3ストック・勝敗（完了）

- 1P（青）と 2P（橙）を左右に配置
- 1P はキーボードとタッチ、2P は矢印キー
- 画面下への落下でストックが 1 つ減る（四方向の KO 境界は Milestone 04）
- 3 ストック
- 足場上へ復活。直後は落下で連続してストックが減らない
- ストック 0 で勝敗。R キーまたはタップで再戦

## Milestone 03: 通常攻撃・ヒット判定（完了）

- 1P は J、2P は Enter、スマホは攻撃ボタン
- 通常攻撃は 1 種類。startup / active / recovery
- Hitbox は攻撃中だけ有効。Hurtbox は被弾用。物理コライダーとは分ける
- 向いている方向へ Hitbox を出す
- 1 回の攻撃は同じ相手に 1 ヒット
- 攻撃中も移動できる（`canMoveDuringAttack`）
- ダメージ% と吹き飛ばしは Milestone 04

## Milestone 04: ダメージ%・吹き飛ばし・KO境界（完了）

- 各 Fighter が `damagePercent` を持つ。ヒットで増え、KO 後の復活で 0% に戻る
- 通常攻撃のダメージは 8%。`AttackDefinition` に置く
- 吹き飛ばしは `baseKnockback + ヒット後のダメージ% × knockbackScaling`
- 方向は前方やや上。角度は `knockbackAngleDegrees`
- `knockbackLockMs` のあいだは移動入力で速度を上書きしない。終了後も横速度は残り、空中で減衰する。着地すると通常移動に戻る
- KO 境界は左・右・上・下。`PlaceholderStage` の設定
- HUD にストックとダメージ%を出す
- F3 で Hurtbox と KO 境界を表示する。普段はオフ
- 本格的なヒットストップと被弾硬直はまだ入れない

## Milestone 05: もちまるの性能と固有アクション（完了）

- `CharacterDefinition` に移動、ジャンプ回数、重力、重量、通常攻撃、必殺、上必殺を置く
- 1P はもちまる。HUD の名前は「もちまる」
- 2 段ジャンプ。着地と KO 復活で回数を戻す
- 通常攻撃「ぺち」。3 段コンボにはしていない
- 必殺「ぐるぐる突進」。上入力が強いときは「ふうせんジャンプ」
- ふうせんジャンプは空中で着地まで 1 回。上昇中に弱い Hitbox
- weight で吹き飛ばしを割る。もちまるは 1.0
- 2P は仮キャラのまま。通常攻撃と 1 段ジャンプ
- 必殺が成立したフレームでは、同じフレームのジャンプを発動せず、ジャンプ回数も減らさない
- 3 段コンボ、方向通常攻撃、ぽてち固有性能はまだ入れない

## Milestone 06: ぽてちの性能と固有アクション（完了）

- 2P をぽてちに置き換え。HUD の名前は「ぽてち」
- 移動は遅め、ジャンプは低め、weight は 1.4、重力は 1.1
- 通常攻撃「どすっ」。発生は遅め、威力と吹き飛ばしは強め
- 必殺「どっすーん！」。`slam` で前方へ跳んでから着地時に 1 回だけ当たる。着地しない場合は最大時間で解除する
- 上必殺「ばねジャンプ」。ふうせんジャンプより低く、横移動も小さい
- 空中の上必殺は着地まで 1 回。上必殺が成立したフレームはジャンプを消費しない
- 仮表示は物理ボディより大きい。Hurtbox と足場判定のサイズは変えない
- 方向通常攻撃、3 段コンボ、本番画像はまだ入れない

## Milestone 07: スマホUI/UX仕上げ（完了）

- 横持ち前提。左手は仮想スティック、右手はジャンプ・攻撃・必殺だけ
- 右手は必殺を上、ジャンプを左下、攻撃を右下に置く。タッチ領域は 64 CSS px
- 攻撃は赤、必殺は紫、ジャンプは青。押しているあいだは縮んで明るくなり、枠が白くなる
- スティックは左下。入力中はノブが指の方向へ動き、離すと中央へ戻る
- スティックと各ボタンは pointerId ごとに持つ。右手を離しても左の移動は残る
- タッチ端末の縦向きでは「端末を横向きにしてください」を出し、操作 UI は出さない
- HUD はスマホでは左上にもちまる、右上にぽてち。Safe Area の内側に置く
- PC ではスティック、タッチボタン、縦向き案内を出さない
- 判定は画面幅ではなく、粗いポインタかつホバー不可またはタッチ可能
- 方向つき通常攻撃とゲームパッドはまだ入れない

## Milestone 08: おひるね草原・ステージ縮小（完了）

- ステージ定義 `ohirune_meadow`。出現、復活、KO 境界、足場、縮小フェーズを持つ
- 中央のメイン足場（幅 820）と、左右上部の浮遊足場
- 180 秒で浮遊足場を予告のあと消す。300 秒でメイン足場を幅 520 まで左右均等に縮める
- 当たり判定は表示と同じフレームで更新する。消えた場所にいたキャラクターは落ちる
- KO 境界は縮めない。再戦でシーンを初期状態に戻す
- `?shrink=fast` で 10 秒と 20 秒に短縮できる。F3 のときだけ経過時間と Phase を出す
- 7 分以降の吹き飛ばし補正は入れていない

## Milestone 09-A: もちまるの Sprite 表示（完了）

- 1P のもちまるだけ本番スプライト。2P のぽてちは仮表示のまま
- 表示は `CharacterView`。物理ボディ、Hurtbox、Hitbox のサイズは変えていない
- 接続したアニメーション: idle、run、jump、fall、special_roll、up_special、hit
- ぺちは `mochimaru_attack.png` の 4 コマ。衝撃の星は隣のコマへ少し入る

## Milestone 09-A2: もちまるの表示定義（完了）

- フレーム番号、倍率、足元、オフセットは `AnimationVisualDefinition` に置く
- 再生するフレームは定義側の配列。idle と jump と fall は `[0, 1]`
- attack シートを足せば、ゲームロジックを変えずに仮演出を外せる
- F3 に表示中のアニメーション名とフレームを出す
- 右向き画像を基準にし、左向きは flipX
- ぽてちの本番画像、ステージ背景、UI 素材は Milestone 09-B 以降

## Milestone 09-B: ぽてちの Sprite 表示（完了）

- 2P のぽてちだけ本番スプライト。もちまるの表示設定と性能は変えていない
- 接続したアニメーション: idle、run、jump、fall、attack、special_slam、up_special、hit
- 走りは 6 コマ。どっすーん！はしゃがみ、跳び、空中、急降下、着地、硬直を技の段階に合わせて出す
- ばねジャンプは先頭 3 コマ。見た目の体の高さは約 96px
- 物理ボディ、Hurtbox、Hitbox、ダメージ、吹き飛ばしは変えていない

## Milestone 09-C: おひるね草原の本番アート（完了）

- 背景と足場の見た目だけ。Collider、KO 境界、縮小の秒数は変えていない
- 背景は 1672×941 を 1280×720 に合わせて置く
- メイン足場は上面が平らな `main_platform_left.png` を、左右端を残して中央だけ短くする

## Milestone 09-D: HUD とヒット表示（完了）

- 名前、丸いストック、ダメージ% を半透明パネルにまとめた。性能は変えていない
- 50% 以上はオレンジで太く、100% 以上は赤でさらに大きい
- ヒット位置に短い火花。ぐるぐる突進とどっすーん！は大きく、上必殺は中くらい
- 被弾の白フラッシュは 100ms。KO は短い表示だけで、復活は待たない
- 勝敗は「もちまる WIN」「ぽてち WIN」。再戦は R とタップのまま
