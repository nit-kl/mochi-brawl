# INPUT_SPEC

## 1. 共通入力モデル

入力デバイスからキャラクターを直接操作しない。
全デバイスを `PlayerInput` に変換する。

```ts
export type PlayerInputState = {
  moveX: number;   // -1.0 .. 1.0
  moveY: number;   // -1.0 .. 1.0
  jump: boolean;
  attack: boolean;
  special: boolean;
  dodge: boolean;
};
```

## 2. スマホ

横持ち前提。見た目と余白は `docs/UI_SPEC.md`。

タッチ UI を出す条件は、画面幅ではない。`(pointer: coarse)` かつ、`(hover: none)` または `navigator.maxTouchPoints > 0`。PC の縦長ウィンドウでは出さない。Chrome のデバイスモードは粗いポインタとホバー不可になるので、同じ条件で確認できる。

縦向きのあいだは操作を受け付けず、「端末を横向きにしてください」を出す。横向きに戻すと案内は消える。画面の向き固定 API は使わない。

### 左手

- 仮想スティック。左下の固定位置。指の場所へ浮かばない
  - 左右: 移動
  - 上: 上方向技入力（`moveY < -0.5` で上必殺）
  - 下: 下方向入力
  - 斜めも `moveX` と `moveY` を同時に出す
  - 指を離すとノブは中央へ戻り、移動量は 0

### 右手

ボタンは 3 つだけ。必殺を上、ジャンプを左下、攻撃を右下に置く。これ以上は増やさない。

- ジャンプ
- 攻撃
- 必殺

スティックを上に倒した状態で必殺を押すと、上必殺になる。左右だけでは別の必殺にならない。
攻撃、必殺、ジャンプは、押したフレームだけ `true` になる。
スティックを押したまま右手を押しても、左の移動は切れない。ポインタはスティックと各ボタンで別々に持つ。

### 技派生

方向と組み合わせた通常攻撃、空中通常攻撃の差別化はまだ実装しない。
必殺は、上入力が強いときだけ上必殺、それ以外は通常必殺。

## 3. PCキーボード

1P と 2P でキーを分けている。同じキーを両方に割り当てない。

### 1P

- A / D: 左右移動
- W / Space: ジャンプ。W を押しているあいだは上方向入力（`moveY = -1`）
- S: 下方向入力（`moveY`。移動には使わない）
- J: 通常攻撃
- K: 必殺。W を押したままなら上必殺。必殺が成立したフレームはジャンプしない。上キーを押したまま始まった場合は、そのキーで入ったジャンプも戻す

### 2P

`local_vs` のときだけ、この割り当てを使う。`cpu` では 2P のキーは作らない。

- ← / →: 左右移動
- ↑: ジャンプ。押しているあいだは上方向入力（`moveY = -1`）
- ↓: 下方向入力（`moveY`。移動には使わない）
- Enter: 通常攻撃
- . （ピリオド）: 必殺「どっすーん！」。↑ を押したままなら「ばねジャンプ」。必殺が成立したフレームはジャンプしない。上キーを押したまま始まった場合は、そのキーで入ったジャンプも戻す

ジャンプ、攻撃、必殺は、押したフレームだけ `true` になる。
回避（Shift）とゲームパッドはまだ結線していない。`dodge` は `false` のまま渡す。

## 3.1 CPU

`cpu` モードの 2P だけ `CpuInput` を使う。1P のキーボードとタッチには足さない。`local_vs` では作らない。

Fighter へは今までと同じ `PlayerInputState` を渡す。CPU かどうかの分岐は Fighter に置かない。

判断は 100〜250ms に 1 回。その間は横移動だけを続ける。攻撃と必殺は、判断したフレームだけ `true` になる。詳しくは `docs/CPU_AI.md`。

## 4. ゲームパッド

- Left Stick: 移動
- A / Cross: ジャンプ
- X / Square: 攻撃
- Y / Triangle: 必殺
- LB / L1: 回避

## 5. 自動補助

- 近距離では相手方向へ自動振り向き
- 崖つかまり自動
- 上必殺での空中移動
- 微小段差は自動で乗り越える
