# STAGE_SPEC

## おひるね草原

初期の1vs1基本ステージ。
見やすさ・復帰練習・対戦の基本を優先する。

## 初期形状

- 中央: 大きなメイン足場
- 左右上: 小さな浮遊足場を各1つ
- 左右: 場外判定
- 下: 落下KO判定

## フェーズ

### Phase 1: 0〜3分

通常状態。

### Phase 2: 3〜5分

左右の小足場が少しずつ崩れる。

### Phase 3: 5〜7分

メイン足場の左右端が段階的に狭くなる。

### Phase 4: 7分以降

中央の小型足場のみ。
吹き飛ばし倍率を上げ、決着を促進する。

## 実装上の注意

- ステージ縮小中にプレイヤーを即死させない
- 足場消失前に揺れ/亀裂などの予兆を出す
- コリジョン変更と見た目の変化を同期する
- スマホ画面でも崖位置を視認しやすくする
