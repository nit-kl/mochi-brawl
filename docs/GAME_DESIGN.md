# GAME_DESIGN

## 1. ゲーム概要

`mochi-brawl` は、かわいい小動物キャラクターを操作して戦う、スマホ/PC両対応の2D Web対戦アクションゲーム。

見た目はやさしく、操作は少なく、対戦中は位置取り・攻撃タイミング・復帰判断で差が出る設計を目指す。

## 2. コアルール

- 基本対戦: 1vs1
- 勝敗: 相手の3ストックをすべて失わせた側が勝利
- 時間制限: 原則なし
- ダメージ: 蓄積式
- ダメージが高いほど吹き飛び距離が増える
- 場外へ一定距離以上飛ばされると1ストック失う
- アイテム: 初期プロトタイプではなし

現在の仮ステージでは、キャラクターの中心が KO 境界（左 -200、右 1480、上 -300、下 920）の外へ出ると 1 ストック失う。ダメージは % で溜まり、高いほど吹き飛ぶ。技の数値は `AttackDefinition` に置く。

## 3. 長期戦対策

長時間の逃げ・膠着を防ぐため、ステージ自体を変化させる。

- 0〜3分: 通常
- 3分〜: 左右の小足場が崩れ始める
- 5分〜: メイン足場の左右端が縮小
- 7分〜: 中央足場のみ。吹き飛ばし補正を上げる

プレイヤーに強制タイマーを意識させるのではなく、背景演出や足場変化で終盤感を出す。

## 4. 操作思想

スマホでは右側に3ボタンのみ配置。

- 攻撃
- 必殺
- ジャンプ

左側は仮想スティック。

方向入力と攻撃/必殺を組み合わせることで技を変化させる。

## 5. 自動補助

スマホでの操作負担を下げるため、以下を自動化する。

- 崖つかまり
- 敵の近距離での自動振り向き
- 攻撃方向の軽い補正
- 小さな段差の自動乗り越え
- 復帰時の上方向補正

## 6. PC版

PCではタッチUIを非表示にし、ゲーム画面を広く見せる。

- Keyboard
- Gamepad

両方に対応する。

## 7. MVP

最初の完成目標は以下。

- もちまる vs ぽてち
- おひるね草原
- 3ストック制
- ダメージ蓄積 / 吹き飛ばし / 場外KO
- スマホ/PC双方で操作可能
- ステージ縮小
