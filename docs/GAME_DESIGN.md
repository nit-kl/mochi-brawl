# GAME_DESIGN

## 1. ゲーム概要

`mochi-brawl` は、かわいい小動物キャラクターを操作して戦う、スマホ/PC両対応の2D Web対戦アクションゲーム。

見た目はやさしく、操作は少なく、対戦中は位置取り・攻撃タイミング・左右と上への吹き飛ばしで差が出る設計を目指す。

## 2. コアルール

- 基本対戦: 1vs1
- 勝敗: 相手の3ストックをすべて失わせた側が勝利
- 時間制限: 原則なし
- ダメージ: 蓄積式
- ダメージが高いほど吹き飛び距離が増える
- 場外へ一定距離以上飛ばされると1ストック失う
- アイテム: 初期プロトタイプではなし

おひるね草原では、キャラクターの中心が左 -200、右 1480、上 -300 の外へ出ると 1 ストック失う。この境界は試合中に動かない。下方向の KO は無効で、見えない床が残る。見える足場は中央の草原と左右の浮遊足場だけで、台座は置かない。ダメージは % で溜まり、高いほど吹き飛ぶ。技の数値は `AttackDefinition` に置く。

## 3. ステージ

おひるね草原は時間で狭くしない。浮遊足場も消さない。決着は、左右または上へ吹き飛ばして KO することです。

## 4. 操作思想

スマホ横画面では中央にゲーム画面を置き、その外側のページ右端に4ボタンを配置。

- 攻撃
- 必殺
- ジャンプ
- 防御

ページ左端は仮想スティック。

方向入力と攻撃/必殺を組み合わせることで技を変化させる。

## 5. 自動補助

スマホでの操作負担を下げるため、以下を自動化する。

- 崖つかまり
- 敵の近距離での自動振り向き
- 攻撃方向の軽い補正
- 小さな段差の自動乗り越え
- 空中での上方向の位置取り

## 6. PC版

PCではタッチUIを非表示にし、ゲーム画面を広く見せる。

- Keyboard
- Gamepad

両方に対応する。

## 7. MVP

最初の完成目標は以下。

- タイトル、キャラクター選択、ステージ選択を経て対戦を始める。1P が選んだキャラクターの相手は、もう一方
- スマホは CPU 対戦。タッチ UI は 1 人分。PC は「ひとりで」で CPU、「ふたりで」で同じキーボードの 2 人対戦
- CPU は入力だけを作る。近づき、近距離で通常攻撃、中距離で時々必殺、相手が上ならジャンプと上必殺。左右の KO 線に近いときは中央へ戻る。下からの復帰はしない
- もちまる vs ぽてち
- おひるね草原
- 3ストック制
- ダメージ蓄積 / 吹き飛ばし / 場外KO
- 対戦中は名前、ストック、ダメージ% を見ながら戦う。当たった位置に短い火花が出る
- スマホ/PC双方で操作可能
- おひるね草原。時間では狭くしない
