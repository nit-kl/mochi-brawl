# UI_SPEC

スマホ操作 UI。ゲームの論理解像度は 1280×720 のまま。横向きの対戦中だけ、ページ左右に操作専用エリアを作り、ゲームキャンバスを中央に収める。タイトル・選択画面と PC は従来通り全幅で表示する。

## 端末

タッチ UI と縦向き案内は `isTouchLayout()` が true のときだけ使う。

- `(pointer: coarse)` である
- かつ `(hover: none)` または `navigator.maxTouchPoints > 0`

PC では仮想スティック、タッチボタン、縦向き案内を出さない。防御は 1P が L、2P が /。

縦向きは、上の条件に加えて `(orientation: portrait)`、または高さが幅より 40 CSS px 以上大きいとき。案内文は「端末を横向きにしてください」。横向きに戻ると class `is-visible` を外して消える。

## 右手

ゲーム画面外のページ右端に、上からジャンプ・攻撃・必殺・防御を縦一列に置く。

- ボタン直径は画面の高さに応じて 38〜58 CSS px
- 左右の操作エリアは最低 76 CSS px。Safe Area がある場合はその分だけ広げる
- キャンバスには重ねず、独立した DOM 要素でタッチ入力を受ける
- 攻撃は赤、必殺は紫、ジャンプは青、防御は緑。ラベルは黒
- 押しているあいだは 0.93 倍に縮み、塗りを明るくし、枠を白く太くする

## 左手

仮想スティックはゲーム画面外のページ左端に固定する。

- 外円の直径は最大 76 CSS px。狭い端末では操作エリア内に収まる大きさにする
- ノブは外円の 44%。ドラッグ中もポインタを保持し、指を離すと中央へ戻る
- 入力中はノブが指の方向へ動き、外円の枠が太くなる
- 指を離すと中央へ戻る

## HUD

`BattleHud` が半透明の角丸パネルを出す。左上はもちまる、右上はぽてち。中身は色付きの丸、名前、残ストックの丸、ダメージ%。

- 0〜49%: 40px。もちまるは青、ぽてちは茶色
- 50〜99%: 46px、太字、`#e07a00`
- 100% 以上: 54px、太字、`#d01212`
- PC: パネルの外側を左 (24, 16)、右 (1256, 16)
- スマホ: Safe Area と 16 CSS px の内側。操作 UI はキャンバスの外側

## ヒットと勝敗

`HitEffectView` がヒット位置に火花を約 280ms 出す。判定は変えない。通常攻撃は小さく、上必殺は中、ぐるぐる突進とどっすーん！は大きい。被弾中の白表示は 100ms。

KO は画面内に短い光と「KO!」を出す。復活や勝敗の待ち時間は足さない。勝敗パネルは「もちまる WIN」または「ぽてち WIN」。再戦は R または「再戦」、キャラクター選択へ戻るのは Esc または「キャラ選択へ」。画面の空きをタップしても再戦しない。

## ブラウザの標準操作

ゲームキャンバスと縦向き案内だけを対象にする。

- `touch-action: none`
- `overscroll-behavior: none`
- 選択と長押しメニューを抑える
- `viewport-fit=cover` と `user-scalable=no`

## 画面の流れ

起動はタイトル。スマホは「はじめる」で CPU 対戦へ進む。PC は「ひとりで」と「ふたりで」を選び、← → と Enter でも決められる。

キャラクター選択では4キャラから1Pと2Pを選ぶ。同キャラ対戦もできる。PC は方向キーまたは A D で選び、Enter または Space で決定、Esc でタイトルへ戻る。スマホはカードをタップしてから「決定」。選択中は対戦用のスティックと4ボタンを出さない。

ステージ選択は一覧から選ぶ。今はおひるね草原だけで、背景を縮小して見せる。決定で対戦が始まる。

左の HUD が 1P、右が 2P。名前と色は選んだキャラクターに合わせる。

## 責務

- `TouchControlsView`: ページ左右のスティックとボタンの DOM 表示
- `TouchInput`: DOM のポインタ入力を `PlayerInputState` に変換する
- `BattleHud`: 名前、ストック、ダメージ% のパネル
- `MobileHudLayout`: そのパネルを Safe Area の内側へ動かす
- `HitEffectView`: ヒットの火花
- `MatchResultView`: KO の短い表示と、再戦 / キャラ選択へ戻る
- `FlowButton`: タイトル、選択、勝敗で使うボタン
- `deviceLayout`: タッチ判定、縦向き、Safe Area、キャンバス枠
